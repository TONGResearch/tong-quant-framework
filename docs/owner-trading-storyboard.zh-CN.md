# Tong Quant 交易 Storyboard（目标流程）

这是一份用户视角的目标流程，不是当前可运行的交易系统，也不是投资建议。
截至 2026-10-10，PIT 就绪度仍为 `UNSUITABLE`；执行与通知默认关闭。
当前系统止于研究、验证能力和研究型组合提案。Paper Trading、券商接入、
订单、成交、自动交易均未实现，并继续冻结。

## 今天：研究流程

1. 数据源留下原始证据、时间戳、来源、质量和缺失警告。监测服务检查
   数据契约；监测通过不等于数据适合历史验证。
2. Discovery 发现候选，Hard Screening 淘汰不合格对象，幸存者进入
   Research Queue。你看到入选和淘汰的理由，而不是自动买入清单。
3. ResearchReport 同时写出 thesis、counter thesis、证据和失效条件；
   InvestmentAssessment 与 InvestmentScore 仅辅助研究排序。
4. 历史验证入口检查 PIT 数据集、可信度和样本完整性。若所声明的数据集
   不是 `USABLE`，ValidationRequest 必须被拒绝；不能把缺失样本藏起来。
5. PortfolioProposal 和 RiskAssessment 只展示研究型仓位与风险情景。
   你自行审阅；这里没有券商连接、订单或真实资金动作。

## 未来：经独立批准后的完整流程

| 场景 | 系统应做什么 | 你应看到或决定什么 |
|---|---|---|
| 开市前 | 核对交易日、公司行为、数据时效、券商状态和持仓；任何关键证据缺失就暂停。 | 当日是否具备运行条件和暂停原因。 |
| 机会研究 | 分层筛选、研究、评分和 PIT 验证；保留反方论证与失败原因。 | 可追溯的研究报告，而非单一指标的买点。 |
| 组合构建 | 依据已接受的验证结果、总风险预算、单标的与行业上限、相关性、流动性、现金和压力测试生成仓位提案。 | 每个候选占比的计算依据，以及不采用它的理由。 |
| Shadow 与 Paper | 经另行批准后，用真实时间顺序观察假设决策，并在隔离账本模拟成交、费用、滑点与无法成交。 | 模拟结果与真实行情偏差；不能把模拟收益视为实盘收益。 |
| 半自动执行 | 经另行批准后，刷新价格和风控，向你展示精确的标的、数量、价格边界、有效期限及原因；授权须绑定这些内容。 | 逐笔批准或拒绝；研究通知不能充当交易批准。 |
| 券商交互 | 通过认证过的市场专用适配器提交一次性意图，接收回报并核对成交、撤单、拒单及券商持仓。 | 订单真实状态；超时或断线时先核对，不能盲目重发。 |
| 持仓期间 | 持续检查风险预算、失效条件、数据新鲜度、市场规则和券商账实一致。 | 例外事件、暂停原因与人工接管入口。止损价不是保证成交价。 |
| 全自动模式 | 仅在独立审计和明确批准后，在指定策略、资金上限、市场、券商和时段内运行；触发限制即停。 | 定期审阅日志、绩效、异常和策略版本，随时可暂停。 |

所有未来执行路径都必须在关键条件不明时 fail closed。A 股与海外市场
分别应用生效日期正确的交易日历、T+1/可卖数量、板块涨跌幅、费用、
币种和券商规则。系统不能用研究评分直接生成订单，也不能通过修改
一个配置值越过数据、验证、风控和人工批准门槛。

## 你届时的角色

你定义允许的市场、资金上限、最大回撤和人工审批范围；审阅研究假设、
验证结果与异常；决定是否启用或暂停某个经批准的版本。即使进入
全自动模式，券商权限、规则变化、数据失效和事故处理仍需要人负责。
当前只应进行研究和证据积累，不应把本文件当作上线授权。
