# 数据接口接入现状

日期：2026-10-28，马来西亚时间。本表核对当前代码和已有留存证据，
不是今天所有网站的实时连通性、账号权限或数据授权检测。不读取或展示密钥。

## 不是不需要接口，而是接入和离线研究分开

数据来源/接口 → 适配器 → 原始证据留存 → 校验及可得时点 → 本地数据库
→ 筛选/研究/验证。

抓取阶段需要访问提供商；固定时点研究应优先读取已留存版本，方便复现，
不会每算一次 MACD 或核对一项财务值都重新请求网站。聊天中的网页搜索也不
自动变成项目内的数据接入。网页 JSON、官方 PDF 下载路径和商业 API 是不同
接口形式；都须经过项目的数据边界，不能直接授权投资或执行。

| Finnhub | 路线图中的新闻/披露/基本面方向 | 当前 src/scripts/config 未发现实际适配器或接入配置，不能称已接通；未来需先定义数据范围、权限与保存边界 |

这些来源没有一个被默认信任。Trust、Coverage、AvailabilityPrecision、
HistoricalContinuity、CrossProviderConsistency 分别评价。来源数量、下载成功、
相同数值或同源镜像不能自动提高信任。总体 PIT 仍为 UNSUITABLE。

## 接下来真正缺什么

1. 可复核的历史财务发布/修订、证券上市/退市/停牌、公司行为与历史股票池，
   不能拿今天抓到的完整表回填过去。
2. 港股/马股更多发行人与金融子行业的稳定原始披露与参考数据，不能用两份 PDF
   声称全市场完成；对应会计、币种、股类和期间定义要单独审查。
3. 同口径、同时间范围的真实跨源基线；先检查独立性及字段可比性，再谈一致率。
4. 如需分钟/VWAP 等技术，须有符合该市场粒度、时效和使用范围的数据。
   日线快照不能假装分钟数据或实时行情。

这不是“把所有网站都接进来”或“先买更贵套餐”就能解决的问题。
按当前最高优先级补明确的数据缺口；购买、注册、登录、授权与密钥配置应在明确
需要时才请 Tong 操作。证券账户、网页能看行情与程序 API 权限不是同一件事。

## Tong 当前需要做什么

本轮不需要新增 token、提供密码或购买数据。继续使用已留存样本打通只读研究。
未来若具体数据缺口需要账号/权限，将说明提供商、端点、数据范围和验证方式后
再请求操作。密钥只通过本地环境配置，不粘贴到对话、仓库、日志或数据库。
未经批准，不接券商交易接口、不提交订单、不将数据接入当作实盘批准。
