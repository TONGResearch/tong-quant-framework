# 非金融长期研究评分提案 V1

日期：2026-10-27（马来西亚时间）。状态：DRAFT / 待 Tong 审查。
这是一份设计提案，不是运行时配置，也不批准任何数据、评分、策略或交易。
Tong 随后已确认首发必须覆盖四市场、金融和非金融，并接受只读输出，详见
[当前首发矩阵](../four-market-readonly-release-2026-10-27.zh-CN.md)。
本文件保留为 A股非金融子提案，不再代表整个首发范围；其中权重/阈值仍未获批准。

## 定位

先针对 A 股非金融公司的长期研究；不适用于银行、证券公司、保险公司、基金或海外公司。
继续遵循 Discovery → Hard Screening → Research Queue → Research → Investment Scoring → Validation。
评分只分配研究注意力和比较已经研究的候选，不按全市场分数直接买入。

FinancialResearchModule 当前始终不评分。ValueResearchModule 虽有 Survival/Cycle/Valuation/Growth
字段和依赖接口，也不等于已经实现了可信的财务评分公式；调用方提供四个数字不能充当定义或来源资格。
实现本提案前须独立批准来源准入与财务口径；不能只把 financial_scoring_authorized 改成 true。

## 两个角色不能混淆

- Financial：检验会计口径、期间、版本、现金/债务及盈利质量，为研究提供基础事实和财务判断。
- Value：结合 Financial、Industry、Policy 和已验证的估值背景，判断长期持有论点是否成立。

同一份利润/现金流不能同时在 Financial 与多个 Value 维度中重复当作独立利好。
最终 InvestmentScore 继续使用现有合同并结合 assessment status；不新造第二套投资总分。
当前 InvestmentScore 的权重/缺失组件政策尚非本试点的已验证权重；本提案不修改这些运行时默认值。

当前默认 require_all_components=false、minimum_scored_components=2。这个通用能力不能当作
首发策略的资料准入：首发必须另行冻结必要模块、明确 NOT_APPLICABLE 与可选缺失的区别，
不能只剩两个高分模块就重新归一化为“资料充分”。必要 Financial/Value/技术条件不能因总分配置而绕过。
这项策略级准入与具体数值分档一起审查；本轮不修改通用构建器或已有历史评分。

## 四个维度的候选规则

| 维度 | 必需证据和判断问题 | 缺口或反例处理 |
| --- | --- | --- |
| Survival | 现金限制、债务到期/利息、现金流构成、资产负债及持续经营风险；不能只有总负债/总资产比 | 有息债务、受限资金或现金来源不清时不可给“安全”分；财务困难不等于数据缺失，须分别记录 |
| Cycle | 公司收入/利润的连续可比期间、行业景气/供需/库存与政策证据；区分一次性恢复与持续改善 | 单期环比、市场状态或一则新闻不能独自证明周期上行；没有行业/历史证据则不评分 |
| Valuation | 合格的价格、股本/股类、公司行为和盈利/净资产口径；选择适合该行业与利润状态的方法 | 不把半年利润年化；不以 CNY 股本代替股数；亏损/非正分母不输出常规正 PE；没有资格的 TTM 算术不直接进入估值 |
| Growth | 可比收入、归母利润、现金创造与投入资本回报的多期证据，核查扩张质量和反向论点 | 非正基期不强算百分比增长；ROE 不代替 ROIC；不得因单期高增长抵销硬筛选失败或财务口径缺失 |

候选 Value 内部权重建议为 Survival 30%、Cycle 20%、Valuation 25%、Growth 25%。
这只是待审查/预注册的研究权重，不是默认配置、经验上已证明有效的参数或收益承诺。
缺少必要维度时不重分配权重凑满分，输出 INCOMPLETE/INSUFFICIENT_DATA，而不是“中性 50 分”。
权重敏感性和相同证据重复计权必须进入验证。Financial 与 InvestmentScore 的跨模块权重另行审查，
不得把这四个权重误当整个系统的总权重。

每个维度应先产生具备证据与反例的离散研究结论：支持、混合、反对、证据不足。
数值分档与阈值必须在观察样本外结果之前预注册、版本化并经审查；本文件不冒充已完成这项校准。
未确定数值分档期间仍不允许开启 Financial/Value 自动评分。不能将人工/AI 自报结论直接转换成合格分数。

## 技术与市场环境

首个长期假设沿用现有 long_term_confirmation 的研究条件：真实硬筛选、合格的 Financial/Value
结论与置信度，以及趋势结构、动量证据。现有 60 的条件置信度默认值是软件配置，不是已证明的最佳门槛。

- MACD 与 KDJ 属于同一动量家族，不能算两张独立赞成票。
- 均线、三线形态和格兰维尔延续型证据保留相关性上限；均值回归与趋势延续分别描述。
- 指标冲突表示需要等待或论点不充分，不等于公司不值得研究，也不自动等于卖出。
- 改进海龟保留独立四确认分支；不把长期价值规则偷偷改成盲目突破。
- Market Regime 保持高权重研究变量，不能单独批准/否决机会；数据质量、硬筛选及风控否决仍有效。
- 已有动态止损是论点失效参考，不保证触价成交；首版不下单，也不假定能当日卖出。

## 必须先通过的准入

1. 样本/股票/行业与实际市场身份匹配，真实筛选和队列存在。
2. 原始数据、单位、期间、修订、可得时间与文件/批次可复核；必要定义齐全。
3. 来源资格、可信度、历史连续性和独立一致性分别审查；LOW 不因哈希一致就自动升级。
4. 报告/行情时效规则、股本与公司行为连续性有明确已批准口径；默认 UNASSESSED 不能当作 PASS。
5. 每一分档/权重/必要维度/缺失行为和失效条件预先登记，不按结果倒改。
6. 报告必须有 thesis、counter thesis、可证伪失效条件，置信度来自证据质量/完整度/模块一致性/PIT，非简单平均。

ROIC 口径、有息债务组成、受限现金与行业周期数据仍是实际缺口。
如首发不使用某项，必须明确修改研究假设与验证问题、记录理由并重新审查，不能从既定策略中静默删除。

## 验证与失败处理

预注册的验证必须区分研究正确性、重建质量和决策质量，并使用现有 PIT/Replay 准入。
Walk-forward、最终 OOS 使用限制、稳健性、因子/家族消融、不同市场状态、失效条件和成本/不可退出风险均须覆盖。
具体样本数、观察期限、比较基准和允许误差留待验证规格审批；本提案没有伪造这些结果或阈值。
若样本不足或策略无效，返回证据不足/否决并修订规格，而不是增加评分复杂度或开放实盘。
